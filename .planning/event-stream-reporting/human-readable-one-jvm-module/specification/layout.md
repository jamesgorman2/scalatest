# Consolidated human-readable output for one JVM module: layout

This document indexes the acceptance criteria for how the human-readable output lays out its lines: its tree, where each line sits, each line's text and colour, the summary line, and Mill's prefix. It is part of [../SPECIFICATION.md](../SPECIFICATION.md). [../SPECIFICATION.md](../SPECIFICATION.md) § Acceptance criteria defines the notation these criteria use for an event log.

## Parts

- [layout-tree.md](layout-tree.md) — the tree of modules, runs, suites, scopes and tests, where each line sits, and collapsed subtrees.
- [layout-lines.md](layout-lines.md) — the text and colour of scope, test, module, run, abort, count and output lines, failure, cancel and abort messages, the summary line, and Mill's prefix.
- [layout-messages.md](layout-messages.md) — the text and colour of messages, and where they sit among a node's lines.
