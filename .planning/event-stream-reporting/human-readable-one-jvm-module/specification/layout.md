# Consolidated human-readable output for one JVM module: layout

Acceptance criteria for how the human-readable output lays out its lines: its tree, where each line sits, each line's text and colour, and Mill's prefix. Part of [../SPECIFICATION.md](../SPECIFICATION.md), whose § Acceptance criteria sets the terms these criteria use, *an event log holding* events among them.

## Parts

- [layout-tree.md](layout-tree.md) — the tree of test run labels, suites, scopes and tests, where each line sits, and collapsed subtrees.
- [layout-lines.md](layout-lines.md) — the text and colour of scope, test, label, abort, count and block lines, failure, cancel and abort messages, and Mill's prefix.
- [layout-messages.md](layout-messages.md) — the text and colour of messages, and where they sit among a node's lines.
